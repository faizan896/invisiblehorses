Built around the boundaries that matter

Access with a scope.

Give each agent its own API key. Choose read or payment permissions, see when the key was used, and revoke it immediately.

A budget before a balance.

Company limits, agent limits and vendor allowlists are checked server-side. Pending work reserves budget so simultaneous requests cannot spend it twice.

Work that outlives a tab.

Durable jobs handle queued requests. The worker rechecks the current rules and records settlement with balanced ledger entries.

Clear about what ships.

This release is a working agent payments control plane with isolated demo workspaces, hashed keys, deterministic policies, owner approvals, durable processing and an append-only audit log.

Payments settle in the internal demo ledger. External bank payouts and crypto transfers are not connected in the public workspace. This is not a licensed payment processor or a production custody service.
