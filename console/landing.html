06 / The boundary

Before real money.

The public app cannot accept deposits or execute real payments. Connecting a company requires more than changing an API key.

  1. A supported payment provider.

    A company needs its own approved provider account, verification and an eligible bank, card or wallet connection.

  2. An execution integration.

    The backend must submit the intended payment type, verify provider callbacks and handle retries without creating duplicate transfers.

  3. Reconciliation and reversals.

    Payment states must match provider records, including pending, failed, settled and reversed outcomes. Internal ledger completion is not proof of an external transfer.

  4. Company access and operations.

    Team identity, account recovery, access reviews, monitoring and a tested recovery process are needed for a company deployment. The current recovery key does not verify a company or replace team login.

Buying API credits through a checkout and sending a bank payout are different integrations. The appropriate provider depends on the payment type and the company's country.

07 / Good to know

A few answers.

Can I use real cash today?

No. Balances and payments in the public workspace are internal test credits. Bank payouts, card charges and cryptocurrency transfers are not connected.

Does my agent need my bank credentials?

No. The agent receives an Invisible Horses API key scoped to its own requests. There is no place to connect production bank credentials in this release.

What happens when I retry a payment request?

The same agent, idempotency key and payload return the original record. A changed payload with that key is rejected. New invoices need new keys.

How do I return to a workspace?

Save its private recovery key in a password manager. Use Restore workspace on the start page if you change browser or your seven-day access expires. Restoring invalidates previous owner sessions, revokes agent keys and cancels unsettled requests. Saved history remains. Losing both access and the key means there is no email recovery option.

Can I cancel or refund a payment?

You can cancel a queued or pending request before it settles. Completed internal ledger payments cannot be cancelled. External refunds and disputes are not implemented.

Does choosing a route in the planner send money?

No. The route planner is a separate planning preview within this product. It compares estimates; it does not send a payment or configure the workspace worker.
